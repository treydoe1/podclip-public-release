# Independent development

Podclip was created from the author's plain-English description of the desired
podcast-editing workflow, with implementation assistance from a coding agent.
The author did not decompile, disassemble, translate, inspect, or copy any
third-party plugin code or package when creating Podclip.

The private development repository is retained as an archive of independent
creation. Its dated commits, prompts, planning notes, source files, test records,
and release work are preserved in their original history.

Public releases are produced from a separate repository with a clean public
history. The public repository excludes private prompts, working notes, signing
materials, old release assets, and unrelated showcase content.
